# My Website

A beautiful, responsive website built with HTML, CSS, and JavaScript.

## Features

- 📱 Fully responsive design
- 🎨 Modern gradient color scheme
- ✨ Smooth animations and transitions
- 📧 Contact form functionality
- 🚀 Fast and lightweight

## Sections

- **Home**: Hero section with call-to-action button
- **About**: Information about the website
- **Services**: Showcase of services with hover effects
- **Contact**: Contact form for visitors

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Customize the content to match your needs

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
